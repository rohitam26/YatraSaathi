1. Introduction

YatraSaathi ("the Application", "we", "our") is an open-source travel companion application built with Flutter for Android. The application monitors travel progress, triggers audible arrival alarms at pre-configured stations, and facilitates safety check-in messages to emergency contacts.

We believe personal location history is private. This document provides complete transparency regarding how YatraSaathi processes data locally on your device, what minimal network services are contacted, and how your privacy is protected.

2. Scope of the Policy

This policy applies to the YatraSaathi mobile application. YatraSaathi operates with an offline-first architecture without cloud servers, remote databases, user registration, or advertising telemetry.

3. Information the Application Accesses

  • Geographic Location: High-precision GPS coordinates, horizontal accuracy, speed, and timestamps.
  • Passenger Profile & Contacts: User display name, mobile phone number, designated emergency contact names, and phone numbers.
  • Journey Configurations: Stop titles, coordinates, alert radii, and custom check-in message templates.
  • Hardware Capabilities: Android alarm audio stream (STREAM_ALARM), vibration hardware, wake lock, and system notifications.

4. Location Information & On-Device Processing

When tracking is active, YatraSaathi reads device GPS coordinates to calculate remaining distance using the spherical Haversine formula.

Zero Location Telemetry: All GPS distance computations, accuracy evaluations, and dwell-time checks take place 100% on your device. Your coordinates are never sent to or logged on any external server during journey tracking.

Background Location & Foreground Service

To ensure alerts sound even when the screen is locked, YatraSaathi runs an Android Foreground Service with a persistent status notification. You can pause or cancel tracking at any time.

5. Journey, Destination & Profile Data

All journey stops, custom radii, emergency contacts, and passenger settings are saved strictly in your device's private local storage (SharedPreferences). No travel itineraries are uploaded to any server or cloud database.

6. SMS and Safety Check-In Messages

Native SMS Composer (Default)

Upon arrival, YatraSaathi prepares a pre-filled check-in message and opens your native Android SMS application using an sms: intent. No message is sent automatically without you pressing "Send" in your SMS app.

Direct SMS Background Service (Private / Sideload Builds Only)

For custom sideloaded builds where automated background dispatch is explicitly desired, direct telephony via Android's SmsManager is supported only after explicit user configuration and runtime permission approval (SEND_SMS). This feature is disabled by default.

7. External Map & Geocoding Services

To provide visual map picking and address lookup, YatraSaathi contacts standard public map APIs via HTTPS:

Provider Purpose Data Transmitted
OpenStreetMap
tile.openstreetmap.org		 Displays map imagery in the location picker. Tile coordinates ($z, x, y$), standard User-Agent header, device IP.
Komoot Photon
photon.komoot.io		 Primary destination search by name. User search query string (e.g. landmark or station name).
Nominatim (OSM)
nominatim.openstreetmap.org		 Reverse geocoding (coordinates to address label). Tapped latitude/longitude coordinates, User-Agent header.

These requests occur only when actively browsing the map or searching for a location—never during background transit tracking.

8. Data Sharing & Third-Party Trackers

  • No Analytics SDKs: No Google Analytics, Firebase, Sentry, or tracking tools are embedded.
  • No Advertising Networks: Zero ads and zero advertising identifiers.
  • No Data Monetization: We never collect, sell, or rent personal data.

9. Permissions & User Control

Permission Type Purpose
ACCESS_FINE_LOCATION Location Real-time GPS proximity detection for destination alarms.
ACCESS_BACKGROUND_LOCATION Location Monitors travel progress while the screen is locked or idle.
FOREGROUND_SERVICE_LOCATION Service Android 14+ requirement for foreground transit tracking.
POST_NOTIFICATIONS Notifications Displays persistent tracking status and high-priority alarms.
VIBRATE & MODIFY_AUDIO_SETTINGS Hardware Tactile feedback and alarm audio routing via STREAM_ALARM.
SEND_SMS (Optional) Telephony Direct background SMS dispatch (private custom builds only).

10. Data Retention & Deletion

You have full ownership of your data. You may edit or delete saved journeys and contacts inside the application at any time. Clearing application data in Android System Settings or uninstalling YatraSaathi permanently wipes all local data.
