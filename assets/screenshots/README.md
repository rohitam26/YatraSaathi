## Capture Guidelines & Privacy Standards

1. **Authentic App Screens Only:** Capture genuine screenshots from an Android device or emulator running the build (`app-debug.apk` or `app-release.apk`). Do not use synthetic mockups or stock images.
2. **Privacy Protection:** Use fictitious names and sample phone numbers (e.g., `+91 98765 43210`) in all captured input fields. Never capture or expose personal phone numbers, addresses, or private contact details.
3. **Consistent Theme:** Capture all screenshots using the same visual theme (Light Mode with consistent system status bar appearance).
4. **Clean Presentation:** Ensure battery level, Wi-Fi, and time icons in the status bar are clean and uncluttered.
